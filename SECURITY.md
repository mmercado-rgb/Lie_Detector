# Security Policy

## Reporting a Vulnerability

If you discover a security issue or integrity weakness in this project,
please report it responsibly.

Do not open a public issue describing the vulnerability before reporting it
privately.

You can report vulnerabilities by contacting the repository maintainer.

Please include:

- a description of the issue
- steps to reproduce the issue
- the potential impact
- any suggested mitigation if known

## Scope

This project is an experimental research framework. Security guarantees are
limited and the system should not be used in safety-critical or production
environments without independent review.

## Supported Versions

No formal support guarantees are provided. Users are responsible for verifying
the behavior of the version they choose to run.
